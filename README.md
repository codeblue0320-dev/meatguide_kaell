# 🥩 정육 도감 (Meat Cuts Guide)

한국식·서양식 정육 방식으로 나눠 보는 소·돼지 부위 도감 웹앱(PWA).

- 🐄 소고기 — 한국식 대분할 10 · 소분할 39 / 서양식 US Primal 9
- 🐖 돼지고기 — 한국식 대분할 7 · 소분할 25 / 서양식 Primal 7
- 📄 총 97개 부위 상세 페이지 (특징 · 조리법 · 손질법 · 품질 판별)

---

## ⚠️ 업로드할 때 딱 하나만 지키세요

**이 폴더 안의 파일들을 "폴더 없이" 저장소 최상단(root)에 그대로 올립니다.**

```
저장소 루트/
├── index.html            ← 이 파일 하나에 앱 전체가 들어 있습니다
├── manifest.json
├── sw.js
├── icon-32.png
├── icon-180.png
├── icon-192.png
├── icon-512.png
├── icon-maskable-512.png
├── .nojekyll
└── README.md
```

`index.html` 은 **완전 자립형**입니다. CSS·JavaScript·데이터·아이콘이 모두 그 안에 들어 있어서,
**나머지 파일이 하나도 없어도 앱은 100% 정상 동작합니다.**
나머지는 "홈 화면에 앱으로 추가 / 오프라인 실행"을 위한 부가 기능일 뿐입니다.

### 업로드 방법 (GitHub 웹)

1. 저장소 → **Add file ▸ Upload files**
2. 압축 푼 폴더를 열고 **폴더가 아니라 그 안의 파일들을 전부 선택**해서 드래그
3. **Commit changes**
4. **Settings ▸ Pages** → Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save
5. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 접속

> `.nojekyll` 은 숨김 파일이라 드래그에 안 잡힐 수 있습니다.
> 안 올라가면 **Add file ▸ Create new file** → 파일명 `.nojekyll` 입력 → 내용 비운 채 Commit.
> (없어도 이 앱은 동작합니다.)

### 예전에 올린 파일이 남아 있다면

`app.js`, `style.css`, `data-*.js`, `build-preview.py`, `download` 같은 파일이 저장소에 남아 있다면
**전부 삭제**하세요. 지금 구조에서는 쓰이지 않으며, 남아 있으면 헷갈리기만 합니다.
(GitHub 웹: 파일 클릭 → 우측 🗑 휴지통 아이콘 → Commit)

## 📲 휴대폰에 앱처럼 설치

- **iPhone (Safari)** — 공유 <kbd>↑</kbd> ▸ **홈 화면에 추가**
- **Android (Chrome)** — ⋮ ▸ **앱 설치**

설치하면 주소창 없는 전체화면으로 뜨고, 비행기 모드에서도 열립니다.

## 🔄 화면이 예전 그대로일 때

브라우저와 서비스 워커가 이전 버전을 캐시하고 있을 수 있습니다.

- **PC** — `Ctrl`(Mac은 `Cmd`) + `Shift` + `R`
- **모바일** — 설치한 앱 아이콘을 삭제 후 다시 추가, 또는 브라우저 설정에서 해당 사이트 데이터 삭제

## 🛠️ 내용 수정

`index.html` 한 파일에 모든 것이 들어 있습니다. 텍스트를 고치려면 이 파일에서 해당 문구를 찾아
직접 수정하면 됩니다. (GitHub 웹에서 파일 클릭 → ✏️ 연필 아이콘)

원본 프로젝트(파일이 `js/`, `css/` 로 나뉜 개발용 구조)에서 작업한 뒤
`python3 build-flat.py` 를 실행하면 이 배포용 폴더(`dist/`)가 다시 만들어집니다.
